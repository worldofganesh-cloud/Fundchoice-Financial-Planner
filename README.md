# FundChoice Wealth Planner

This folder is ready to publish with GitHub Pages. The complete website is contained in `index.html`; no build command, dependencies, or external asset folders are required.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository root.
3. Open the repository's **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will display the public website address after deployment completes.
